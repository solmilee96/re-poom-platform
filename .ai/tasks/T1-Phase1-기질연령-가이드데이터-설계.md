# T1 Phase 1: 기질 중심 통합 개선 설계

> 작성: 2026-02-20 | 상태: 진행 중

## 1. 핵심 원칙

### 차별화 포지셔닝

| 일반 발달 가이드 서비스 | 우리 서비스 (괜찮아요) |
|---|---|
| "15개월이면 걸어야 해요" | "신중파 아이는 충분히 안전하다고 느낄 때까지 걷기를 미루는 경향이 있어요" |
| 발달 정보가 **주인공** (체크리스트) | 발달 정보는 **배경 맥락**, 기질이 **주인공** |
| 전달 톤: "~해야 합니다" | "이 시기에 ~인데, 이 기질의 아이는 이렇게 나타나요" |
| 부모 감정: 비교 → 불안 | 부모 감정: 이해 → 안심 |

### 발달 정보 전달 규칙

1. 발달 정보는 **단독으로 나열하지 않는다** (체크리스트 금지)
2. 항상 **"이 시기 아이들은 ~인데, [기질유형]인 [이름]이는 ~"** 패턴으로 전달
3. 발달 이정표는 "기준"이 아니라 "배경 설명"으로만 사용
4. 부모의 불안을 "평균과의 비교"가 아닌 "이 아이의 기질로 설명"한다

## 2. 데이터 구조

### 파일 위치

`web/public/data/temperament-age-guide.js`

### 구조 설계

```
TEMPERAMENT_AGE_GUIDE = {
  [temperamentType]: {
    [ageRange]: {
      summary: "이 기질 + 이 시기의 한 줄 요약",
      
      domains: {
        [domainKey]: {
          general:            "이 시기 일반적 발달 맥락 (배경)",
          withThisTemperament: "이 기질의 아이에게서 어떻게 나타나는지",
          parentTip:          "부모가 할 수 있는 구체적 행동",
          commonWorry:        "부모가 흔히 하는 걱정 (부모 목소리)",
          reframe:            "기질 렌즈로 재해석"
        }
      },
      
      dailyConcerns: {
        [concernKey]: {
          commonWorry:        "부모 목소리로 된 걱정",
          reframe:            "기질 해석",
          tip:                "구체적 팁"
        }
      }
    }
  }
}
```

### 기질 유형 (7종, 기존과 동일)

섬세파 / 에너자이저 / 신중파 / 탐험가 / 순둥이 / 밸런서 / 혼합형

### 연령 구간 (5구간)

| 구간 | 키 | 비고 |
|------|-----|------|
| 0~6개월 | `0-6` | 감각 발달기 |
| 7~12개월 | `7-12` | 이동·애착 형성기 |
| 13~18개월 | `13-18` | 걸음마·자율성 시작 |
| 19~24개월 | `19-24` | 언어 폭발·자아 형성 |
| 25~36개월 | `25-36` | 사회성·자기 조절 |

### 발달 영역 (5영역)

| 키 | 영역 |
|-----|------|
| `grossMotor` | 대근육 |
| `fineMotor` | 소근육 |
| `language` | 언어 |
| `social` | 사회성·정서 |
| `cognitive` | 인지 |

### 일상 고민 (5종, 기존 주제와 동일)

| 키 | 주제 |
|-----|------|
| `sleep` | 수면 |
| `eating` | 식사 |
| `tantrum` | 떼쓰기 |
| `clothing` | 옷입기 |
| `aggression` | 또래·공격 |

## 3. 적용 범위 (behavior → report → chat 통합)

### 3.1 behavior 단계 (고민 선택)

- 현재: 고정 키워드 버튼 (떼쓰기, 수면, 식사...)
- 개선: `[기질유형][연령구간].dailyConcerns`에서 `commonWorry` 텍스트를 동적으로 표시
- 추가: `[기질유형][연령구간].domains`에서도 `commonWorry`를 선택지로 추가
- 부모 목소리 문구로 표시 (예: "너무 돌아다니기만 하고 집중을 못해요")

### 3.2 report 결과지

- 기존 섹션(기질 해석, 양육자 분석, 고민 분석, 팁) 유지
- 추가 섹션: **"[기질유형] [이름]의 [연령] 성장 이야기"**
  - `domains`의 `general` + `withThisTemperament`를 통합 서술
  - 발달 정보가 기질 해석 안에 자연스럽게 녹아 있는 형태
- behavior에서 선택한 고민에 대한 `reframe` + `tip` 강조 표시

### 3.3 chat 상담

- `buildSystemInstruction`에 해당 연령 구간의 가이드 데이터 주입
- 프롬프트 지침 추가: "발달 정보를 언급할 때 반드시 기질과 연결하여 말하세요"
- 채팅 진입 시 선제적 가이드 카드 (Phase 2에서 구현)

## 4. 작업 순서

```
[Step A] 데이터 파일 생성 ← 현재 단계
    ↓
[Step B] behavior 단계 UI + 로직 개선
    ↓
[Step C] report 결과지 섹션 추가
    ↓
[Step D] chat 시스템 프롬프트 고도화
```
