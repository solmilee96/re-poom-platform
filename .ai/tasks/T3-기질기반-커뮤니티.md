# T3: 기질 기반 커뮤니티

> 우선순위: 3순위 | 상태: 🔜 예정 | 목표: 2개월 내

## 목적

기질 데이터가 축적된 충성 고객을 대상으로 폐쇄형 소그룹 커뮤니티를 열어, 최종적인 경쟁 해자(Moat)와 리텐션 도구를 확보한다.

## 핵심 가치

- 커뮤니티는 가장 강력한 리텐션 도구
- 1·2순위 기능으로 데이터 축적 후 오픈 시 폭발력 극대화
- Metcalfe's Law: 네트워크 가치 = 사용자 수²

## 선행 조건

- T1(대화형 상담 고도화)을 통해 기질 데이터가 충분히 축적되어야 함
- T2(리포트 고도화)를 통해 리포트 수령자 풀이 형성되어야 함

## 세부 과제

- [ ] 커뮤니티 MVP 기능 정의 (기질별 공감 게시판)
- [ ] AI 매칭 로직 설계: "나와 같은 고민을 하는 5명의 엄마" 연결
- [ ] 폐쇄형/소그룹 운영 정책 수립
- [ ] 리포트 수령자 대상 베타 초대 프로세스
- [ ] 커뮤니티 가이드라인 및 모더레이션 정책
- [ ] 베타 오픈 후 피드백 수집 및 개선
- [ ] 점진적 확대 전략 수립

## 성공 지표

- 커뮤니티 가입률 (리포트 수령자 대비)
- 주간 활성 사용자(WAU) 증가
- 게시글·댓글 수
- 리텐션율 향상
