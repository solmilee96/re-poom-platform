## 3. 이름 + 조사 자동화 (`getNameI`)

### 규칙 (국립국어원 기준)
- 이름 마지막 글자에 **받침이 있으면** → `이` 추가 (예: 길동 → 길동이)
- **받침이 없으면** → 추가 없음 (예: 지우 → 지우)

### 구현
```javascript
const getNameI = (name) => {
  if (!name) return '';
  const code = name.charCodeAt(name.length - 1);
  if (code < 0xAC00 || code > 0xD7A3) return '이'; // 비한글 기본값
  return (code - 0xAC00) % 28 !== 0 ? '이' : '';
};
```

### 적용 범위
- JSX 화면 텍스트 전체: `{childInfo.name}{getNameI(childInfo.name)}`
- 기질 분석 결과 템플릿 텍스트: `${name}${ni}` (분석 함수 내 `const ni = getNameI(name)`)
- JSX 속성 내 템플릿 리터럴: `${childInfo.name}${getNameI(childInfo.name)}`
- 기질 질문 제목 `{{name}}이(가)`: `.replace()` 체인으로 이름에 맞게 치환
  - `{{name}}이(가)의` → `{이름}{ni}의`
  - `{{name}}이(가)` → `{이름}{ni}가`
